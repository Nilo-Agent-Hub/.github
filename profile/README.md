# Nilo Agent Hub

以开放协议连接 Agent，让接入、消息与会话保持一致。

[官网](https://nilo.feelings.dev/) · [Connector 开发工具包](https://github.com/Nilo-Agent-Hub/connector-protocol) · [反馈与建议](https://github.com/Nilo-Agent-Hub/connector-protocol/issues/new/choose)

## 从开放协议开始

**Nilo Connector Protocol（NCP）** 提供协议规范、Manifest、SDK、示例与一致性检查，帮助开发者独立实现 Connector。接入实现可以独立维护，无需公开自己的源码。

| 入口 | 内容 |
| --- | --- |
| [协议规范](https://github.com/Nilo-Agent-Hub/connector-protocol/blob/main/SPEC.md) | 消息、会话、能力声明与安全边界 |
| [开发指南](https://github.com/Nilo-Agent-Hub/connector-protocol/blob/main/DEVELOPING.md) | Connector 实现、打包与验证 |
| [SDK 与示例](https://github.com/Nilo-Agent-Hub/connector-protocol#readme) | Python / TypeScript 开发工具与参考实现 |
| [贡献指南](https://github.com/Nilo-Agent-Hub/connector-protocol/blob/main/CONTRIBUTING.md) | 问题记录、PR 与检查流程 |

## 参与建设

欢迎通过 [Issues](https://github.com/Nilo-Agent-Hub/connector-protocol/issues) 报告协议问题、提出改进建议，或提交 PR。NCP 开发工具包采用 [MIT 许可证](https://github.com/Nilo-Agent-Hub/connector-protocol/blob/main/LICENSE)；具体兼容范围以协议规范为准。

项目持续开发中，当前公开的开发入口以 NCP 工具包为主。
